# Student Portfolio

A personal student portfolio website built to introduce my academic background, share selected projects, present my technical interests, and provide a simple academic task planner.

## Live Website

[Visit the Student Portfolio](https://wabkur.github.io/student-portfolio/)

## About the Project

This website is a front-end project created as a place to present my learning journey and work in technology. It brings together a short introduction, an about page, a project showcase, an academic planner, and a contact page.

## Website Pages

- **Home (`index.html`)** — introduces me and the purpose of this portfolio.
- **About Me (`about.html`)** — presents my education, interests, career direction, and technical skills.
- **Projects (`projects.html`)** — showcases selected programming and development projects.
- **Academic Planner (`planner.html`)** — lets visitors add tasks, mark them as completed, and delete them. Tasks are saved in the browser using `localStorage`.
- **Contact (`contact.html`)** — provides a contact form with front-end input validation.

## Technologies

- HTML5 for page structure
- CSS3 for layout, styling, and responsive presentation
- JavaScript for planner interactions and contact-form validation
- Git and GitHub for version control and project hosting
- GitHub Pages for deployment

## Run the Project Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/wabkur/student-portfolio.git
   ```

2. Open the `student-portfolio` folder.
3. Open `index.html` in a web browser. You can also use the Live Server extension in Visual Studio Code.

## Notes

- The academic planner stores tasks in the current browser on the device being used. Tasks are not synchronized between different browsers or devices.
- The contact form currently performs front-end validation only. It does not send or store messages because a back-end or form service has not been connected yet.
- Project repository links can be added to the project cards when the individual project repositories are available.
